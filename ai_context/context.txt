# PROJECT OVERVIEW

# Project name:
Study in Germany Guide

# Goal:
Provide information about universities, public transportation, housing, food, and entertainment for international students in Germany.

# Main sections:
- Universities
- Transport
- Housing
- Food
- Entertainment

# Target users:
International students.

# TECH STACK
- Frontend: React JS, TypeScript,

Styling:
Tailwind CSS

UI Components:
21st.dev components
shadcn/ui style components

Backend:
Next.js API routes

Database:
PostgreSQL
Prisma ORM

# COMPONENT RULES

Always use reusable components.

Example components:
Navbar
Hero
Card
Section
Footer

# API RULES

Use Next.js API routes.

Example:

/api/housing
/api/universities
/api/transport

Return JSON responses.

# DATABASE RULES

Use Prisma ORM.

Example tables:

City
University
Housing
Transport

Use relational design.

# CODING RULES

Use functional React components.

Use TypeScript.

Avoid inline styling.
